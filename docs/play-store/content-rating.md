# Alterseinstufung (IARC-Fragebogen)

Kategorie: **Nachschlagewerk, Nachrichten oder Bildung** (Books & Reference).

| Frage | Antwort | Begründung |
|---|---|---|
| Gewalt | nein | — |
| Angst / Horror | nein | — |
| Sexualität | nein | — |
| Sprache | nein | — |
| Drogen / Alkohol / Tabak | nein | — |
| Glücksspiel (echtes Geld) | nein | — |
| Simuliertes Glücksspiel | nein | — |
| Käufe | nein | keine In-App-Käufe |
| Werbung | nein | keine Werbung, keine Ad-SDKs |
| Nutzerinteraktion | nein | kein Chat, keine Kommentare, keine Profile |
| Standortweitergabe | nein | kein Standortzugriff |
| Weitergabe personenbezogener Daten | nein | — |
| Digitale Käufe | nein | — |
| Unmoderierte Inhalte von Nutzern | nein | Inhalte sind fest eingebaut |

Erwartetes Ergebnis: **USK 0 / PEGI 3 / alle Altersgruppen freigegeben.**

Hinweis zur Zielgruppe: „Zielgruppe 13+" wählen, nicht „Kinder". Eine
Einstufung als Kinder-App zieht die Families-Policy nach sich (u. a.
zertifizierte Werbe-SDKs, die hier nicht existieren) und wäre unnötiger Aufwand.
